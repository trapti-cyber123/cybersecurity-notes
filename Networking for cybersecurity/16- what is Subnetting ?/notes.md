# what is subnetting ?
  Subnetting is the process of dividing one large IP network into smaller logical networks called subnets.

[*]  Subnetting ek process hai jisme ek bade IP network ko chhote-chhote logical networks mein divide kiya jata hai, jinhe Subnets kehte hain.

🧠 Simple Example

  Maan lo tumhare paas ek bada network hai:

  192.168.1.0/24

  Isme bahut saare devices connect ho sakte hain.

  Agar tum is network ko 4 smaller networks mein divide karna chahti ho, to subnetting ki help se divide kar sakti ho:

  192.168.1.0/24
  


🔹 Subnetting ki zarurat kyu hoti hai?
1. Network ko divide karna

 It divides a large network into smaller networks.

[*] Bade network ko chhote networks mein divide karta hai.

2. IP addresses ka better use

It helps use IP addresses more efficiently.

[*] Available IP addresses ka better utilization hota hai.

3. Network performance
   
    Smaller networks can reduce unnecessary broadcast traffic.

[*]  Chhote networks banane se unnecessary broadcast traffic ko reduce kiya ja sakta hai.

4. Security & Management

 Different departments or groups can be placed into separate subnets.
 
 [*] Different departments ko alag-alag subnet mein rakha ja sakta hai, jisse network management aur segmentation better hoti hai.

🔹 Important Terms

.IP Address

Device ka logical address.

Example:

192.168.1.10

.Subnet Mask

Ye batata hai ki IP address ka network part aur host part kya hai.

Example:

255.255.255.0

.CIDR

Subnet ko /24, /25, /26 jaise notation mein represent karta hai.

Example: 
      192.168.1.0/24



192.168.1.0/24
