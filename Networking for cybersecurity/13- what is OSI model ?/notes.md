# what is OSI model ?
  OSI = Open Systems Interconnection 
OSI Model is a 7-layer conceptual model that explains how data is transferred from one computer to another over a network.

[*]  OSI Model ek 7-layer conceptual model hai jo batata hai ki network mein ek computer se doosre computer tak data kaise transfer hota hai.

🧱 OSI Model ki 7 Layers

7  	Application 	User/application ko network services dena
6 	Presentation 	Data format, encryption, compression
5	 Session 	Connection/session establish aur manage karna
4 	Transport 	Reliable data delivery aur segmentation
3 	Network 	IP addressing aur routing
2 	Data Link 	Frames aur MAC address ke through delivery
1 	Physical 	Bits ko signals ke form mein transmit karna
