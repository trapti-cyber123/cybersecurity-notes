# what is Firewell ?
  A Firewall is a security system that protects a computer or network from unauthorized access and harmful network traffic.
   It monitors incoming and outgoing traffic and allows or blocks it based on security rules.

[*] Firewall ek security system hai jo computer ya network ko unauthorized access aur harmful network traffic se protect karta hai. Ye incoming aur outgoing traffic ko check karke rules ke according allow ya block karta hai.

# Firewall ka main function. 

  . Incoming traffic ko check karna

  . Outgoing traffic ko monitor karna.

  . Unauthorized connections ko block karna.
  
  . Allowed connections ko permit karna.
  
  . Network ko unwanted/malicious traffic se protect karna.
