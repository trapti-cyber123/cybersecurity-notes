# what is bridge ?
  A Bridge is a networking device that connects two LAN segments and forwards data only to the required segment using MAC addresses.

[*] Bridge ek networking device hai jo do LAN segments ko connect karta hai aur MAC address ki help se data ko sahi network segment tak bhejta hai.
