#  what is Gateway ?

  A Gateway is a networking device that connects two different networks and acts as an entry and exit point for data.

  Gateway ek network device hota hai jo do alag networks ko connect karta hai. Ye ek network se doosre network mein data bhejne ka entry/exit point hota hai.\
  
 # example 
  
Aapka home network → Internet se connect hota hai.

Aapke router ka gateway IP, jaise 192.168.1.1, devices ko Internet tak pahunchne mein help karta hai.

 3. Gateway ka Main Function 

. Different networks ko connect karna.

. Data ko ek network se doosre network tak forward karna.

. Network ke entry/exit point ke roop mein kaam karna.

. Zarurat padne par different protocols ke beech communication/translation karna.

. Local network ko external network, jaise Internet, tak pahunch dena.

4. Default Gateway kya hota hai?

Default Gateway wo device/address hota hai jahan computer un packets ko bhejta hai jinka destination local network ke bahar hota hai.
